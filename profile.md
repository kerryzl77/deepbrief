# Profile

DeepBrief should optimize for an applied AI engineer with an approximately two hour daily
reading budget, prioritizing sources where the value comes from mechanisms, code, evidence,
and operational tradeoffs rather than announcements alone.

High-interest areas:

- Code-grounded agent systems: runtime loops, tool calling, orchestration, context management,
  and coding-agent internals.
- Coding-agent and repository workflows: Codex, Claude Code, diffs, file/path-level verification,
  and implementation impact.
- Agent infrastructure: MCP, tool catalogs, permissioning, sandboxing, isolation, E2B-style
  boundaries, evals, LLM-as-judge, and regression harnesses.
- Document AI and retrieval: extraction reliability, structured outputs, citation hygiene, and
  auditable evidence trails.
- Primary-source applied AI research that connects papers, official docs, repo changes, and
  production engineering practice.

Penalize model-release hype, business news, listicles, and thin announcements.
Penalize unsupported summaries and content without mechanism detail or primary-source evidence.
